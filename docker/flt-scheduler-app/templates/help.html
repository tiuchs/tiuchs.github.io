Getting Started

🔐 User Roles

Role Permissions
User View flights and export daily CSV
Scheduler + Create, edit, and delete flight schedules
Approver + Approve and cancel flight status
Admin + Full system access, settings, backups, user management

📅 Daily Workflow

  1. Morning: Review today's flight schedule on the dashboard
  2. Planning: Schedulers add new flights as needed
  3. Approval: Approvers review and approve planned flights
  4. Execution: Track flight status throughout the day
  5. Closeout: Complete flight closeouts with actual times
  6. Export: Download daily CSV for crew notifications

🔧 Initial Setup (Admins)

  1. Change the default admin password immediately
  2. Add crew members in Crew Management
  3. Add aircraft in Aircraft Management
  4. Create user accounts with appropriate roles
  5. Set website theme preference (light/dark)

Database Backups

✅ Automatic Backups

You're protected automatically!

  • Backups run every 24 hours
  • A backup is created each time the app starts
  • Last 7 days of backups are kept
  • Old backups are automatically deleted
  • All backups are integrity-verified

📦 Manual Backups (Admins)

When to create a manual backup:

  • Before making major changes (bulk deletions, imports)
  • Before software updates
  • At the end of important operations periods
  • Before database maintenance

How: Go to Settings → Admin Settings → Click "Create Backup Now"

⬇️ Downloading Backups

Admins can download backups for off-site storage:

  1. Navigate to Settings → Admin Settings
  2. Scroll to "Database Backups" section
  3. Click "Download" next to any backup
  4. Save to external drive or cloud storage

💡 Best Practice: Download a backup weekly for disaster recovery

🔄 Restoring from Backup

# Stop the application
docker compose -f docker/flt-scheduler down

# Copy backup to main database
cp data/backups/scheduler-backup-YYYYMMDD-HHMMSS.db data/scheduler.db

# Start the application
docker compose -f docker/flt-scheduler up -d

⚠️ Warning: Restoring will replace all current data!

Health Monitoring

🏥 System Health Status

The application monitors its own health automatically:

  • Database Connectivity: Can the app access the database?
  • Database Integrity: Is the database structure valid?
  • Disk Space: Is there enough free space?
  • Backups: Are backups being created successfully?

📊 Health Check Endpoint

curl http://localhost:8080/health

Status Indicators:

  • Healthy - All systems operational
  • Degraded - Minor issues (still functional)
  • Unhealthy - Critical issues (needs attention)

🚨 Warning Signs

Take action if you see:

  • ❌ Application won't start
  • ❌ "Database corrupted" in logs
  • ❌ Can't create backups
  • ⚠️ Slow performance
  • ⚠️ Frequent "database locked" errors
  • ⚠️ Disk space under 100MB

First Response: Check Troubleshooting section below

Troubleshooting

🔧 Common Issues & Solutions

Problem: Can't Access Website

# Check if container is running
docker compose -f docker/flt-scheduler ps

# Restart the application
docker compose -f docker/flt-scheduler restart

Problem: "Database is Locked"

Solution: Wait 5-10 seconds and try again. The system automatically retries locked operations.

Problem: Changes Not Saving

Check:

  • Are you logged in?
  • Do you have the right role (Scheduler/Admin)?
  • Are all required fields filled?

Problem: Backup Failed

# Check disk space
df -h docker/flt-scheduler-app/data/

Solution: Free up space if less than 100MB available

📋 View Application Logs

# View recent logs
docker compose -f docker/flt-scheduler logs --tail=100

# Follow logs in real-time
docker compose -f docker/flt-scheduler logs -f

# Search for errors
docker compose -f docker/flt-scheduler logs | grep -i error

🆘 Emergency: Database Corruption

Critical Issue - Immediate Action Required

  1. Stop the application immediately
  2. Locate the latest backup in data/backups/
  3. Copy the backup to replace the main database
  4. Restart the application
  5. Verify data is correct

💡 See "Restoring from Backup" in Backups section above

Frequently Asked Questions

How do I change my password?

Currently, only admins can reset passwords. Contact your administrator or go to Settings → Admin Settings (admin only).

How many users can use the system simultaneously?

The system supports 10-20 active users comfortably. Thanks to Write-Ahead Logging, multiple users can view and edit data concurrently without "database locked" errors.

What happens if the server crashes?

Your data is protected! The latest backup (max 24 hours old) can be restored. All completed transactions are preserved thanks to database crash recovery features.

Can I manually delete old backups?

Yes (admins only). Backups older than 7 days are auto-deleted, but you can manually delete backups from the data/backups/ directory if needed. Keep at least one recent backup!

Why do I see multiple database files?

You'll see three files:

  • scheduler.db - Main database (your data)
  • scheduler.db-wal - Write-Ahead Log (temporary)
  • scheduler.db-shm - Shared memory (temporary)

⚠️ Never delete WAL or SHM files while the app is running!

How do I export flight data?

Daily Export: Click "Export CSV" on the daily view or visit /daily.csv?date=YYYY-MM-DD

Date Range Export (Admin): Go to Settings → Admin Settings → "Export Scheduled Flights"
