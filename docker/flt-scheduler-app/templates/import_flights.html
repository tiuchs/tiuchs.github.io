Upload CSV File

Upload a CSV file with flight data. The system will automatically generate mission IDs and create any missing crew members or aircraft.

CSV Format Requirements (click to expand)

Required Headers (in this order):

  1. flight_date - Format: YYYY-MM-DD (e.g., 2026-02-25)
  2. launch_time - Format: HH:MM (e.g., 08:00)
  3. recovery_time - Format: HH:MM (e.g., 12:00)
  4. mission_type - Must be "training" or "mission"
  5. mission_title - Description of the mission
  6. atp_company - Must be "A Co", "B Co", or "C Co"
  7. tail_number - Aircraft tail number (e.g., UH-60-001)
  8. aircraft_model - Aircraft model (e.g., UH-60M) - optional if aircraft exists
  9. origin - Origin airfield code (e.g., KFTW)
  10. route - Route waypoints (optional)
  11. destination - Destination airfield code (e.g., KDFW)
  12. pic_name - Pilot in Command name
  13. pic_is_amc - 1 or 0 (1 = PIC is also AMC)
  14. pilot_name - Pilot name
  15. crew_members - Comma-separated crew names (optional)
  16. non_rated_crew - Non-rated crew members (optional)
  17. is_team_flight - 1 or 0 (1 = team flight)
  18. amc_mission_id - AMC mission ID if team flight (optional)
  19. notes - Additional notes (optional)

Example CSV:

flight_date,launch_time,recovery_time,mission_type,mission_title,atp_company,tail_number,aircraft_model,origin,route,destination,pic_name,pic_is_amc,pilot_name,crew_members,non_rated_crew,is_team_flight,amc_mission_id,notes
2026-02-25,08:00,12:00,training,Night Ops Training,A Co,UH-60-001,UH-60M,KFTW,V198,KDFW,Smith,0,Johnson,"SSG Davis, SGT Lee",,0,,Practice NVG approaches
2026-02-25,14:00,18:00,mission,Transport Mission,B Co,UH-60-002,UH-60M,KDFW,Direct,KAUS,Williams,1,Brown,,PVT Martinez,0,,VIP transport

Notes:

  • Mission IDs will be auto-generated based on flight date
  • Crew members not in the system will be automatically added
  • Aircraft not in the system will be automatically added
  • All imported flights start with "planned" status
